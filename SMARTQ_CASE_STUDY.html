→ passive uncertainty

04 — Reality Check (Critical Discovery)

During analysis, a key mismatch emerged: Clinics do not follow digital assumptions.

Real-world behavior:

  • 05:00 PM Clinics functionally open
  • 07:00 AM But bookings start early (7–9 AM)

Patients: call clinics, visit early, get added manually.

Core Gap

Digital systems assume:
Queue starts when clinic opens

Reality:
Queue starts when patients start waiting

10 — Visual System (Design System)

The design system was built to support emotional and behavioral clarity.

Color System

Every color carries meaning. Rule: If a color does not communicate meaning, it is not used.

Primary (Indigo)

Used for trust and stability → healthcare credibility

Teal

Used for confirmations and progress → reassurance

Red

Used for urgency only → immediate action

Amber

Used for transitions and warnings

Typography

Inter

Chosen for clarity under stress: highly legible, neutral tone, strong numeric readability.
Priority: Numbers dominate (queue position, time, status).

Spacing & Component Logic

Spacing controls emotional perception:

  • large spacing → calm
  • tighter spacing → urgency

Queue Card Combines:

position + progress + action → one decision unit

  • Primary CTA ("Leave in X"): always dominant, no competing actions.
  • Live Indicator: subtle pulsing signal, builds system trust.

Motion System

  • pulse → live
  • scale → interaction
  • fade → transition

Design → Behavior Connection

Design ChoiceBehavior Impact
Blue UIreduces anxiety
Red UIdrives urgency
"Leave in"drives action

TRADEOFF: Reduced visual decoration → increased clarity and usability.
